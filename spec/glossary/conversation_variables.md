# conversation_variables

The conversation variables, an FMT-TALK-008 structure loaded from `ALL.VTB` at the start of a session into the record the pointer at `0x0009A928` points to: the count at `+0x04`, the element size at `+0x08`, the kind at `+0x0C` and the pointer to the values at `+0x10` [FND-TALK-006].

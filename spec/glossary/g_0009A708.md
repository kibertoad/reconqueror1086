# g_0009A708

A neutral name: the four-byte global at `0x0009A708` in BLD-GOG-EN. Dubbing's
full-screen callback reads it through DS, passes a nonzero value to sample
playback and then stores zero before replacing the screen [FND-UI-024].
The entry stores the sound-bank loader's result for `dking.666` here;
the callback requests that bank's first sample [FND-UI-026].

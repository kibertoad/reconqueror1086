# fn_00011CC0

A neutral name: the function at `0x00011CC0` in BLD-GOG-EN. It has no neutral names in other builds. It draws the route preview: from the position it receives, each segment to the next route point, with 18 subtracted from the segment's end x, walked along its longer axis with an integer error term, with a dot of frame `counter % 4` of `route_marker_image` whenever either axis is more than 20 from the last dot. The starting counter advances every third call [FND-STRATEGY-031].

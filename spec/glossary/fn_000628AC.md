# fn_000628AC

A neutral name: the function at `0x000628AC` in BLD-GOG-EN. It has no neutral names in other builds. It writes conversation variable `v` of the table it receives from a pointer to the value, as `set_variable` of RULE-TALK-003 does; the rules pass the value itself. The monthly reset and the third joust of a day call it [FND-TOURNEY-001, FND-TOURNEY-004, FND-TALK-006].

## Use

Checked 2026-10-05. The ICO File section describes a counted directory, image
lengths and offsets, bitmap information headers, a color table and paired color
and monochrome masks. It interprets the matching storage in FND-RES-020.
SRC-BMP-REFERENCE supplies palette component order and row alignment. Neither
reference establishes which shipped program consumes these files.

## Known errors

None identified for the stored case. The article's incomplete sample reader is
not a safety contract. Stored image-size variants and consumer acceptance remain
research questions rather than reasons to normalize the files.

## Use

The public GOG build endpoint, checked on the date above, lists English Windows
build `50474999570497193`, version `1.0`, on its public default branch. The owned
installation's `goggame-2110944433.info` identifies that same build. The catalog
also reports private branches; those are not public official patch releases.

lists no official patch for this title. Together with the current distributor
catalog and the owned disc's `VERSION.TXT`, this establishes version 1.0 as the
latest publicly available official edition found in these catalogs. It does not
establish byte identity with every historical retail pressing.

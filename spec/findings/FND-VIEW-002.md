## Observation

The `Map` resource of each of the 42 archives is exactly 32,768 bytes: 16,384 unsigned 16-bit
little-endian block numbers, each below the scene's block count. The number for cell `(x, y)`
is at index `x * 128 + y`. Read this way, the sampled archives' `Viewer` positions (the first two dwords shifted right
by 8) fall on floor cells of the playable area.

## Interpretation

The map is stored in column-major order, and a cell holds the index of the block definition
drawn there.

## Alternatives

None known.

## How to reproduce

Decode `Map` and `Viewer` from an archive and look up the block at the viewer's cell both ways.

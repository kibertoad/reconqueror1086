rules and their adopted procedures, area queues linked to existing open questions,

documentation links. Verify the resulting documentation and canonical gate. Open

promotions caused solely by the migration. Preserve existing IDs and findings.

Original installation bytes, gameplay rules, unrelated worktrees or processes.

## Dead ends

None known.

## Handover

The requirements are verified in docs/documentation-audit.md. Canonical target
and template fast gates pass; local docs, strict source readiness, links and
workflow checks pass. Standard/toolkit file-data location PRs and template
capture/queue PRs are open. Current source states and generated inventory are
reviewed. Commit the migration, perform the required owned-process audit, then
write the completion handover and remove this fulfilled goal file. No gameplay
changes or evidence-status promotions are part of this batch.

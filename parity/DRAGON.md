# DRAGON

| Spec ID | Title | Spec status | Code | Tests | Deviations | Status | Notes |
|---|---|---|---|---|---|---|---|
| `RULE-DRAGON-001` | Dragon encounter | supported | partial | None | None | supported | `Campaign.BeginDragonBattleFromStrategicMap` starts the run at the five lair cells and `Campaign.FinishDragonBattle` ends it. A win does not add 2 to the lance experience, and there is no first-pass wait or sound. `Campaign.BeginDragonBattle` also starts it from the named-location travel screen once the lair is disclosed. The host offers Escape withdrawal, which the original lacks; `SuppressDragonEntry` then keeps the run from starting again until the ridden record leaves the five cells. The host's battle spans later updates, so `Campaign.AdvanceOriginalStrategicPass` defers hostile scheduling when `DragonEntryTriggered` is emitted, where the original runs the encounter inside the player pass. The host samples its current pointer at entry and draws a gold crosshair. |
| `RULE-DRAGON-002` | Crown ending | supported | partial | None | None | supported | `Campaign` crowns the player after a won siege at the location index of the crown victory in `Balance.Victories`, where the original tests for person 100 at the besieged cell. `Campaign.AttemptVictory` and its requirement check have no counterpart in the original. |

# TOURNEY

| Spec ID | Title | Spec status | Code | Tests | Deviations | Status | Notes |
|---|---|---|---|---|---|---|---|
| `RULE-TOURNEY-001` | Monthly tournament site | supported | partial | None | None | supported | The site follows a fixed circuit by date instead of a draw that avoids last month's site, and the win count is not kept. |
| `RULE-TOURNEY-002` | Tournament tent opponents and actions | supported | partial | None | None | supported | The five opponents are a fixed list instead of five character rows drawn for each tournament. |
| `RULE-TOURNEY-003` | Tournament joust wager and rewards | supported | partial | None | None | supported | The stake is fixed per opponent, and the wins do not give fame, strength or dexterity as the rule does. |
| `RULE-TOURNEY-004` | Tournament melee wager, scene and settlement | supported | partial | None | None | supported | The melee is resolved as a field battle with a fixed stake; there is no assault scene, no tier, and no tallies. |
| `RULE-TOURNEY-005` | Practice melee scene | supported | partial | None | None | supported | The scene choice uses the platform generator, and the side sizes are fixed instead of drawn. |

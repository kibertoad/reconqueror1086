# DEV-ASSAULT-002

- Departs from: RULE-ASSAULT-006, RULE-ASSAULT-018
- Reason: When several retainers are ordered to the same cell at once, which one arrives and holds the cell depends in the original on where the thinker cursor stands and which effect slot is free, and so on machine speed and input timing. The rebuild settles such ties in the combatants' authored order, which is x-major map order.
- Setting: None
- Default: mandatory
- Justification: The original has no fixed winner for an exact tie, so there is nothing to reproduce; any rule the rebuild picks is one of the outcomes the original can give. Authored order is the order every other combatant scan uses, and it makes the result repeatable without taking an outcome away from the player.
- Dropped: no
